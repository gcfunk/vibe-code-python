# Vibe Code Python

See if I, as a python novice, can code something non-trivial with copilot, as well as learn more Python in the process

## Files
- `first.py`: Prints a greeting message.
- `snake_game.py`: Classic Snake game where the snake cycles through rainbow colors as it eats. Now features a predator cat that chases the snake!

## How to Run


To run the greeting script:

```
python first.py
```

To play the Snake game:

```
python snake_game.py
```

## Game Features
- **Rainbow Snake**: The snake segments cycle through rainbow colors as you collect food
- **Mouse Food**: Collect cartoon mice to grow your snake
- **Predator Cat**: An orange cat actively hunts your snake! The predator moves every 2 frames and will reset the game if it catches you
- **Dodge Mechanic**: Use WASD keys to quickly dodge in any direction
- **Visual Environment**: Grass background with hedge borders

## Controls
- **Arrow Keys**: Move the snake (Up, Down, Left, Right)
- **WASD Keys**: Dodge in any direction
- **Objective**: Eat mice to grow while avoiding walls, yourself, and the predator!

## Requirements
- Python 3.x

No additional dependencies are required.
